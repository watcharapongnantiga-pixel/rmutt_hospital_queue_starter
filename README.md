# RMUTT Hospital Queue — Web Application

ระบบต้นแบบเว็บไซต์จองคิวและบริหารจัดการคิวโรงพยาบาล RMUTT HEALTH
รองรับการใช้งาน 2 รูปแบบ:
1. **เวอร์ชัน HTML5 + JavaScript + Web Storage** (เปิดใช้งานได้ทันทีบนเบราว์เซอร์ทุกเครื่องโดยไม่ต้องติดตั้งโปรแกรมเซิร์ฟเวอร์)
2. **เวอร์ชัน PHP + MySQL (PDO)** (สำหรับรันบนเว็บเซิร์ฟเวอร์ XAMPP / Apache)

---

## 🚀 วิธีเปิดใช้งานเวอร์ชัน HTML (ไม่ต้องใช้ XAMPP)

คุณสามารถดับเบิลคลิกไฟล์ HTML เปิดบน Google Chrome, Microsoft Edge หรือ Safari ได้ทันที:

1. ดับเบิลคลิกเปิดไฟล์ `index.html` เพื่อเข้าสู่หน้าแรก
2. ไปที่หน้า `login.html` เพื่อเข้าสู่ระบบ โดยมีปุ่ม **"⚡ บัญชีทดสอบระบบด่วน"** ให้คลิกกรอกได้ทันที:
   - **คนไข้**: `patient@hospital.com` / รหัสผ่าน: `patient1234`
   - **เจ้าหน้าที่/แพทย์**: `staff@hospital.com` / รหัสผ่าน: `staff1234`
   - **ผู้ดูแลระบบ (Admin)**: `admin@hospital.com` / รหัสผ่าน: `admin1234`
3. ไปที่หน้า `book.html` เพื่อทำการจองคิวเลือกแผนก วัน และรอบเวลา
4. ไปที่หน้า `ticket.html` เพื่อดูบัตรคิวและสั่งพิมพ์ (Print / PDF)
5. ไปที่หน้า `staff_queue.html` สำหรับเจ้าหน้าที่ในการกดเรียกคิว ข้ามคิว และบันทึกผลการตรวจ
6. ไปที่หน้า `queue_display.html` เพื่อเปิดหน้าจอดิจิทัล (TV Signage) แสดงผลคิวสดพร้อมเสียงสังเคราะห์ภาษาไทย

> **หมายเหตุ:** ข้อมูลทั้งหมดของเวอร์ชัน HTML จะถูกจัดเก็บบน `localStorage` ของเบราว์เซอร์ ทำให้สามารถจำลองการทำงานได้ครบ 100% และซิงก์ข้อมูลข้ามแท็บได้แบบเรียลไทม์

## 📁 รายการไฟล์ในโปรเจกต์

| ชื่อไฟล์ | คำอธิบาย |
|---|---|
| `index.html` | หน้าแรก Landing Page แสดงบริการ ข้อมูลคิว และขั้นตอนการจอง |
| `login.html` | หน้าเข้าสู่ระบบ พร้อมปุ่มกรอกบัญชีทดสอบด่วน |
| `register.html` | หน้าสมัครสมาชิกคนไข้ใหม่ พร้อมออกรหัส HN อัตโนมัติ |
| `dashboard.html` | แดชบอร์ดคนไข้ แสดงโปรไฟล์ ประวัติการนัดหมาย และบัตรคิว |
| `book.html` | หน้าฟอร์มจองคิวออนไลน์ (เลือกแผนก วัน รอบเวลา ระบุอาการ) |
| `ticket.html` | บัตรคิวนัดหมายดิจิทัล (Healthcare Pass) รองรับการพิมพ์ |
| `staff_queue.html` | คอนโซลเจ้าหน้าที่/ห้องตรวจ กดเรียกคิว ตรวจเสร็จ ข้ามคิว พร้อมเสียงอ่าน |
| `queue_display.html` | จอดิจิทัลแสดงผลคิวสด (TV Display) มีเสียงระฆัง + เสียงพูดภาษาไทย |
| `assets/js/app-db.js` | คลังจัดเก็บข้อมูลและจัดการสถานะระบบผ่าน Web Storage |
| `assets/css/` | สไตล์ชีทดีไซน์ Modern Navy Responsive |
| `*.php` | ซอร์สโค้ดฝั่งแบ็กเอนด์ PHP + MySQL สำหรับผู้ที่ต้องการรันบน XAMPP |

---

## 🛠️ วิธีติดตั้งเวอร์ชัน PHP + MySQL (บน XAMPP)

1. แตกไฟล์โปรเจกต์ไปไว้ที่ `C:\xampp\htdocs\rmutt_hospital_queue_starter`
2. เปิด XAMPP Control Panel แล้วกดปุ่ม **Start** ที่ `Apache` และ `MySQL`
3. เปิดเบราว์เซอร์ไปที่ `http://localhost/rmutt_hospital_queue_starter/database/seed_data.php` เพื่อสร้างฐานข้อมูล ตาราง และตารางตรวจ 14 วันอัตโนมัติ
4. เข้าใช้งานได้ที่ `http://localhost/rmutt_hospital_queue_starter/`
